# 日程中心的私人资料工作区

## 看板

日历 → 活动详情 →「打开事件看板」。输入区默认收起，通过工具栏添加便签、图片、链接或 PDF；编辑时展开侧栏，保存后收起。便签有四种纸张颜色；图片按原比例显示，记录放在图片下方。拖动手柄或方向键移动，使用工具栏或 Ctrl / Command + 滚轮缩放（30%–200%），「适应内容」返回资料所在区域。坐标保存为不受缩放影响的画布坐标。

JPEG / PNG / WebP / GIF / PDF 单文件上限 8 MB，保存在私有 `event-board` bucket。PDF 支持打开原文、标题、文件名及人工阅读笔记；**不自动提取 PDF 正文、不做 OCR**。图片签名访问地址一小时到期，刷新更新。不将附件放到公开 GitHub。

## 搜索与关联

日历左侧「搜索与关联」，或看板顶部进入。数据库 RPC 按当前登录账号搜索日程标题、描述、地点、备注、课程、准备内容，以及看板标题、正文、URL、附件文件名。支持中文子串；特殊符号按原文匹配，不当作 SQL 通配符。每次最多200个命中；关系数据加载上限为每类1000行，达到上限会提示。

关系图显示命中节点及一层相邻节点（最多60个可视节点），包含事件所属、看板已有连线、跨事件手动关联、`[[引用]]`。点击节点打开事件看板。搜索结果中的「作为关联起点」可在换关键词搜索后保留，随后在另一个结果点击「连接到这里」。手动关联管理可删除关联，不删除资料。

文字中使用 `[[唯一事件或卡片标题]]`、`[[card-UUID]]` 或 `[[event-UUID|显示文字]]` 建立引用。重名标题不会自动连线；请使用稳定 ID 或手动关联。没有语义模型猜测的隐式关系。

## Obsidian

搜索页「导出到 Obsidian / Markdown」在当前浏览器读取本人资料并下载 ZIP。解压后作为 vault 打开，事件、卡片各一份 Markdown，稳定文件名和双向链接保留关联。附件在 `attachments/`；下载失败会提示，并在相应笔记标明附件缺失。导出附件总量超过100 MB会停止；达到加载上限时拒绝生成不完整备份。

这是手动导出，**不是本地 vault 实时或双向同步**。网页不能自动读写电脑里的 vault。同步需要后续 Obsidian 插件、文件授权或专门服务。Markdown 纯文字导出不会执行用户内容。

## Google Calendar（配置阻塞、尚未实现）

现有 Google 导出 ICS → 导入提议流程可用。自动 OAuth 连接、持久化刷新令牌及后台 Google 同步尚未实现；需要 Google Cloud OAuth client、实际站点回调地址、测试用户/应用发布配置。当前环境没有 Google client ID / secret，不向用户索取聊天中的密钥，不宣称已同步。

建议使用只读 Calendar API，增量数据先进入受控提议。保留 Google 外部 ID 和 etag，远端更新不得覆盖用户在 YING OS 的更正或自动取消已确认安排。

## 部署与验证

增量迁移顺序为 002 → 003，均可重复执行，不重建事件数据或通知 Cron。`Deploy private event boards` Actions 使用已有保护机密执行并核对私有 bucket / RLS / search RPC。前端由 Vercel 构建，数据库迁移成功不等同于前端发布成功。

- `npm test`：缩放坐标、空位分配、唯一引用、歧义引用、一层邻接、Markdown 稳定链接等。
- `npm run test:db`：真实临时 PostgreSQL 17，重复迁移、中文与特殊字符搜索、跨账号读取/写入阻断、外键归属与级联删除。Storage 仅模拟元数据，不能当作托管 Storage 上传验证。
- `npm run build`：生产构建。
- 启动 `npm run start -- --port 3078` 后运行 `npm run test:browser`：需要本机 Chromium，默认 `/usr/bin/chromium`，可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。浏览器使用合成资料、拦截 Supabase 服务边界，验证收起输入区、便签/图片显示、50%缩放拖动、PDF上传、手机无横向溢出、跨查询关联、ZIP下载，无生产数据写入。实际云端登录/上传仍需独立核验。
